# 사후평가 문제은행 — 운영 안내서 (v2)

## 시험 체계

**5과목 100문항 45분**

| # | 과목 | 문항 |
|---|---|---|
| 1 | 개인정보보호법 | 8 |
| 2 | 클라우드기반 시스템 운영/구축 실무 | 24 |
| 3 | 클라우드보안 컨설팅 실무 | 20 |
| 4 | 클라우드기반 취약점진단 실무 | 20 |
| 5 | 클라우드 모의해킹 실무 | 28 |

JSON의 `cat` 필드에는 **이 번호(1~5)를 그대로** 넣는다. 과목명을 문자열로 적어도 인식하지만, 오타·특수문자(`/`, `·`) 위험이 있으니 숫자를 쓸 것.

---

## 1. 파일 구조

```
index.html              ← 앱 엔진. 데모 문항 10개 내장
manifest.webmanifest
sw.js
icon-192.png  icon-512.png
data/
  index.json            ← ★ 콘텐츠 목록 + 버전. 이게 단일 원본
  bank-001.json         ← 문제은행 배치
  glossary.json         ← 용어사전
  notes.json            ← 개념정리
```

**앱에서는 콘텐츠를 추가·수정할 수 없다.** 두 사람이 서로 다른 문항을 갖게 되는 일을 막기 위해 업로드·붙여넣기 기능을 전부 뺐다. 콘텐츠는 저장소의 `data/` 폴더에서만 들어온다.

각 사람의 **회독·오답노트·기록은 자기 기기 안에만** 저장된다. 서버가 없으니 섞이지 않는다.

---

## 2. 콘텐츠 갱신 방법 (관리자 = 나)

`data/` 에 파일을 올리고 **`data/index.json` 을 고친다.**

```json
{
  "ver": "2026-08-05-01",
  "files": ["bank-001.json", "bank-002.json", "glossary.json", "notes.json"]
}
```

- `files` — 앱이 받아갈 파일 목록. 여기 없는 파일은 무시된다
- `ver` — **이 값을 바꿀 때만** 앱이 새로 받아간다. 파일만 바꾸고 `ver`을 그대로 두면 반영되지 않음

날짜+순번(`2026-08-05-01`)처럼 쓰면 헷갈리지 않는다.

앱을 켜면 자동으로 확인하고, `ver`이 달라져 있으면 전부 다시 받아 **교체**한다. 즉시 반영하고 싶으면 상대방에게 앱 하단 **정보 탭 → 콘텐츠 새로 받기**를 누르라고 하면 된다.

`data/` 폴더는 서비스워커가 **캐시하지 않도록** 설정해서, 두 사람이 항상 같은 최신 버전을 받는다.

### 데모 문항

지금은 `demo-bank.json`(10문항, `"demo": true`)이 등록돼 있다. **실제 문제은행 파일이 하나라도 들어오면 데모는 자동으로 무시된다.** `files` 목록에서 빼도 되고 그냥 둬도 된다.

## 3. 문제은행 스키마

```json
{
  "type": "bank",
  "id": "001",
  "title": "1차 문제은행",
  "items": [
    {
      "n": 1,
      "cat": 2,
      "sub": "AWS 네트워크",
      "type": "mc",
      "q": "질문 본문",
      "opts": ["보기1", "보기2", "보기3", "보기4"],
      "ans": 2,
      "exp": "1~2줄 해설",
      "diff": 2
    }
  ]
}
```

| 필드 | 필수 | 설명 |
|---|---|---|
| `n` | ✔ | 문항 번호. 화면에 `#001`로 표시. **전체 은행에서 유일해야 함** |
| `cat` | ✔ | 과목 번호 **1~5** |
| `sub` | — | 소분류. 문항 우측에 표시만 |
| `type` | ✔ | `mc`(4지선다) · `ox`(진위형) · `sa`(주관식) |
| `q` | ✔ | 질문 본문 |
| `opts` | `mc`만 | 보기 배열. **순서 고정, 셔플하지 않음** |
| `ans` | ✔ | `mc`: 0부터 세는 인덱스 / `ox`: `"O"` 또는 `"X"` / `sa`: 정답 문자열 **배열** |
| `fmt` | `sa`만 | 답안 형식 지시. 예: `"한글로 작성, 띄어쓰기 금지"` |
| `exp` | 권장 | 해설. 결과·오답노트에서 노출 |
| `diff` | — | 난이도 1~3 |

**같은 `n`이 두 배치에 있으면 ID가 큰 배치가 이긴다.** 오답 정정은 패치 배치 한 장으로:

```json
{ "type":"bank", "id":"001p", "title":"001 정정", "items":[ { "n":35, "…": "…" } ] }
```
`files` 배열에 `"bank-001p.json"`을 추가하고 `ver`을 올리면 끝.

주관식 채점은 **공백·대소문자·문장부호를 제거한 뒤 완전일치**다. 동의어를 넉넉히 넣어둘 것.
```json
"ans": ["서명", "전자서명", "디지털서명", "시그니처"]
```
채점 후 결과 화면의 **이 답도 정답으로 인정** 버튼을 누르면 그 답이 **그 사람 기기에만** 등록된다. 둘 다에게 적용하려면 JSON을 고쳐야 한다.

## 4. 용어사전 스키마

```json
{
  "type": "glossary",
  "items": [
    { "term": "가명정보", "en": "Pseudonymized Data", "cat": "개인정보",
      "def": "추가 정보 없이는 특정 개인을 알아볼 수 없게 처리한 정보.",
      "rel": ["익명정보", "재식별"] }
  ]
}
```
`term`·`def` 필수. 여기의 `cat`은 필터용 자유 문자열이라 과목 번호와 무관하다.

## 5. 개념정리 스키마

```json
{
  "type": "notes",
  "items": [
    { "cat": 3, "title": "위험평가 4가지 접근법",
      "body": "## 종류\n- 베이스라인 접근법\n- 상세위험 분석법\n\n## 승인\n- DoA 승인 주체는 **경영진**" }
  ]
}
```
`cat`은 과목 번호 1~5. `body`는 간이 마크다운 지원: `## 소제목`, `- 목록`, `**굵게**`, `` `코드` ``. 표는 지원하지 않으니 목록으로 풀어 쓸 것.

## 6. 출제 엔진

### 회독 순서 (기본 모드)

**이번 회독에서 안 본 문항을 전부 소진할 때까지 이미 푼 문항은 나오지 않는다.** 100문항이면 10문항씩 10라운드를 돌아야 1회독이 끝나고, 그때 자동으로 2회독으로 넘어간다.

같은 회독 안에서의 순서는 **틀린 이력이 있는 문항 우선**(가중치 4+오답횟수, 나머지 1). 검증 결과 오답 문항이 평균의 5배 빈도로 먼저 배치된다.

요청 문항 수가 남은 미완 문항보다 많으면, 미완 문항을 전부 채운 뒤 부족분만 이전 회독에서 가져온다.

### 나머지 모드

| 모드 | 동작 |
|---|---|
| 순수 랜덤 | 회독 무시, 전체에서 균등 랜덤 |
| 오답만 | 오답노트에 담긴 문항만 |
| 실전 모의고사 | 과목별 8/24/20/20/28로 100문항 + **45분 카운트다운**, 시간 종료 시 자동 채점 |

### 경보 단계

정답률에 따라 상단 게이지가 국가 사이버위기경보 4단계로 움직인다.

| 정답률 | 단계 |
|---|---|
| 90% 이상 | 관심 |
| 75~89% | 주의 |
| 60~74% | 경계 |
| 60% 미만 | 심각 |

## 7. 배포 (GitHub Pages)

1. **Public** 저장소 생성 (Private이면 Pages가 안 켜짐)
2. 파일 업로드 — `data/` 는 `Add file → Create new file`에서 파일명에 `data/index.json`처럼 입력하면 폴더가 자동 생성된다
3. **Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save**
4. 몇 분 뒤 `https://<계정>.github.io/<저장소>/` 주소 생성
5. 폰에서 접속 후 홈화면 추가
   - iOS는 **Safari**로 → 공유 → 홈 화면에 추가
   - Android Chrome → ⋮ → 앱 설치

앱 껍데기는 캐시되니 오프라인에서도 열린다. 단, `data/`는 캐시하지 않으므로 **콘텐츠 갱신 확인은 온라인일 때만** 된다.

> ⚠️ 브라우저 사이트 데이터를 지우면 회독·오답노트가 사라진다. 정보 탭의 **학습 기록 내보내기**로 가끔 백업할 것.
